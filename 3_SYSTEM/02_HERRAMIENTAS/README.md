# AUNEA System — Herramientas

Esta carpeta contiene herramientas ejecutables utilizadas por AUNEA.

## Regla

**Herramienta = se usa.**

Una herramienta sirve para analizar, operar, calcular, demostrar, configurar o entregar trabajo de AUNEA. No se presenta por sí sola como producto vendible salvo que una fuente canónica la promueva expresamente a producto.

La documentación humana y los activos de negocio permanecen gobernados en Google Drive.
