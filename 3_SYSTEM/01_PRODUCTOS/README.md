# AUNEA System — Productos

Esta carpeta contiene implementaciones técnicas de productos de AUNEA System.

## Regla

**Producto = se vende.**

Un producto es una solución de AUNEA System destinada a comercialización e implantación para clientes. La documentación comercial, de negocio y los activos humanos permanecen gobernados en Google Drive; GitHub conserva únicamente la implementación técnica, schemas, componentes y artefactos ejecutables que correspondan.

No se crea un producto nuevo en esta carpeta sin fuente canónica y decisión/alcance aprobados.
